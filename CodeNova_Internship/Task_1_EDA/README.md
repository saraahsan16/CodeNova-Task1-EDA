
# CodeNova Internship - Task 1
## Exploratory Data Analysis (EDA)

### Project Overview
This project performs Exploratory Data Analysis on the Wine Recognition dataset using Python.

### Objectives
- Understand dataset structure and statistics.
- Identify missing values and duplicate records.
- Detect potential outliers using the IQR method.
- Visualize correlations and feature distributions.
- Identify patterns through pairwise scatter plots.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

### Dataset
Wine Recognition dataset from Scikit-learn.

### Visualizations
1. Correlation Heatmap
2. Feature Distribution Histograms
3. Boxplot
4. Pairwise Scatter Plot

### How to Run
Install the required libraries:

pip install pandas numpy matplotlib seaborn scikit-learn

Run the Python file:

python eda_analysis.py

### Output
The project generates visualizations and a cleaned CSV dataset in the outputs folder.

### Conclusion
The project explores the Wine dataset through statistical analysis, data cleaning and visualization to understand feature distributions, relationships and potential outliers.
